## Historical material

Other audit, benchmark, experiment, and handoff documents in this directory are records of particular runs or revisions. They are not current installation instructions, blanket dataset permissions, or proof that an artifact is downloadable. Check each document's scope, referenced commit, environment, and evidence before reusing a result.

This cleanup preserves those files and their paths rather than silently rewriting or deleting research history. The publication status page is the entry point for current availability; the model's historical manifest remains a reported-run record.
