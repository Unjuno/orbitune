Designed for listening, not waiting

Generate. Hear. Continue.

The published A2-512 Base runs locally in the browser. Future reviewed LoRA variants use the same Base-bound Web runtime rather than a separate playback stack.

01

Stream while it composes

Generation advances in small batches while WebAudio schedules a bounded look-ahead buffer. You do not wait for a whole song to finish.

02

Keep the model local

ONNX graph bytes are SHA-256 verified before inference. The PWA can cache the reviewed model and runtime dependencies for offline use.

03

Change the future, not the past

The stream carries compressed model state forward. Stop or switch variants to begin a new trajectory; old music is not reconstructed from state alone.
