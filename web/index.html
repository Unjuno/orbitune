Primary mode

Listen while it composes.

Start once, then let the generator stay slightly ahead of playback. You can change decoding while the stream is running; the new settings affect future events without resetting the model state.

Structure/instrument temperature is applied to event type, channel, PROGRAM and BANK decisions. Note/control temperature remains separate, so lowering note randomness does not have to force instrument selection into the same low-temperature regime.

What runs here

Generation and sampled rendering are separate, pinned components.

  • Generation: Orbitune A2-512 research/non-commercial checkpoint through ONNX Runtime Web/WASM.
  • Decoding: selectable nucleus, top-k, min-p or hybrid filtering with separate structural/instrument temperature.
  • Playback: GeneralUser GS 2.0.3 SF2 through SpessaSynth 4.3.14 AudioWorklet synthesis.
  • PROGRAM, BANK, CC, pedal, pitch bend, pressure and MIDI channel 10 percussion are sent to the SoundFont synthesizer as MIDI messages.
  • The live monitor keeps only a bounded recent event list; the model runtime still uses bounded recurrent/context state.
